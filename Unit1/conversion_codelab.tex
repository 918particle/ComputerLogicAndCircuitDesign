\section{Code Lab: \texttt{bin()} and \texttt{hex()}}

\begin{enumerate}

\item Python converts a decimal integer to binary using \texttt{bin()}. Try:

\begin{verbatim}
print(bin(10))
print(bin(15))
print(bin(32))
\end{verbatim}

Python includes the prefix \texttt{0b} to indicate a binary value.

\item Decimal integers can be converted to hexadecimal using \texttt{hex()}.  Try:

\begin{verbatim}
print(hex(10))
print(hex(31))
print(hex(42))
\end{verbatim}

Python includes the prefix \texttt{0x} to indicate hexadecimal.

\end{enumerate}
