\begin{enumerate}
\item Imagine a circuit that mixes a train of impulses (Fig. \ref{fig:1} (left)) with an analog waveform, then holds the voltage constant between impulses. (a) If we had an \textit{analog comparator} that was HIGH if each constant voltage was greater than a reference voltage, and LOW if it was not, then we could translate the constant voltages into binary numbers.  If the code 11 in Fig. \ref{fig:1} (right) represents 3V, and 00 represents 0V, what is the voltage resolution? (b) What is true about the waveform for sampling intervals 9-13?
\item In Fig. \ref{fig:2} (left), $V_{\rm ref} = +8$ Volts, and the op-amp comparators act as the \textit{analog comparators} mentioned in exercise 1.  (a)  Determine the binary code output of the 3-bit flash ADC in Fig. \ref{fig:2} (left), given the input signal in Fig. \ref{fig:1} (right), given the encoder enable pulses shown. (b) If the enable pulse frequency in Fig. \ref{fig:2} (right) were halved, determine the binary numbers represented by the resulting digital output.  Is any information lost?
\end{enumerate}
